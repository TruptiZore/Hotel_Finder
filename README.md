# Hotel_Finder
## Hotel Finder

A simple Hotel Finder web application built using JavaScript and Express.js. It allows users to explore hotels, view hotel-related information, and make bookings through a simple and user-friendly interface.
<br><br>
## Features
1. Hotel Finder homepage
2. Attractive hotel landing page
3. Home, About, Services, Privacy, and Booking sections
4. View available hotels
5. Hotel booking functionality
6. User-friendly navigation
7. Responsive design
8. Light/Dark mode option
9. Express.js backend for handling server-side functionality
<br><br>
